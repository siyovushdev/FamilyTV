# Explore / Weather V1 — native debug preview

26 сентября 2026. Реализован полный preview, установлен и проверен на H728. Production promotion и commit не выполнялись.

1. **Реализация.** Один illustrated Explore world с пятью физическими локациями; активна только Погода, остальные честно показывают «Скоро». Intro → выбор солнечной/теневой тарелки → перемещение льда → два одинаковых стартовых кубика → видимое постепенное таяние → спокойное наблюдение. Гипотеза сохраняется без correct/wrong. Ask Lumi остаётся в сцене результата и последовательно показывает солнце → тепло → остаток льда на солнечной тарелке → воду. Repeat запускает объяснение с начала, сохраняя результаты. Новый опыт: два физических укрытия, установка выбранного предмета, затем отдельная «Проверить», затем сравнение защищённого и открытого льда. Пять состояний Lumi выражены native halo, pulse, мягкими кругами и указанием внимания; наград нет.

Adventure/Discovery runtime и KnowledgeResolver изучены; Activity/runtime, записывающие Journey/history, и Qwen-backed resolver не создаются. Две реплики соответствуют curated weather knowledge, свободного чата нет.
