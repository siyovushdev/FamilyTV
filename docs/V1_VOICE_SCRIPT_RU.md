# FamilyTV V1 Voice Script (Russian)

**Status:** V1_CANDIDATE script — ready for talent / HQ TTS recording  
**Blocker if unrecorded:** `FINAL_VOICE_RECORDING_REQUIRED`  
**Runtime:** offline package / common assets only

Pacing: one short thought → pause → next thought. Prefer spoken beats over long sentences.
