# Age Complexity Guidelines (FamilyTV)

ReadingSupportMode stays **independent** of age. These are authoring guidelines, not hard biology.

## Bands (metadata `ageMin` / `ageMax`)

### 3–5
- 2–3 choices max
- Very short spoken instructions (≤ ~8 words per beat)
- Concrete objects only
- Heavy visual affordances; text secondary

### 5–7
- 3–4 choices
- Simple relations (“чётное”, “живаёт”)
- Short reasoning with one hint level early

### 7–9
- Patterns and light multi-step
- Still prefer visuals + speech over dense text
- Scaffolding must not require reading labels

## Validation

AUDIO_FIRST release ERROR if choices are text-only without voice aliases / visual glyphs.  
WARNING if choice count exceeds band guideline or narration is dense.
